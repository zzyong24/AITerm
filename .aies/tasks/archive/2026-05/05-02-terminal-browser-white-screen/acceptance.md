# Acceptance Criteria — Terminal 浏览器白屏修复

## P0 — 必须通过

### A1：localhost 能正常加载
- 打开浏览器 Tab，输入 `http://localhost:3000`（或任意本地端口）
- 预期：页面正常渲染，不白屏

### A2：外部网站能正常加载
- 输入 `https://example.com`
- 预期：页面内容显示（不因 X-Frame-Options 白屏）

### A3：刷新按钮有效
- 点击工具栏刷新按钮
- 预期：当前页面重新加载

### A4：URL 输入回车跳转
- 在 URL 框输入新地址按回车
- 预期：webview 导航到新 URL，URL 框同步更新

### A5：缩放不破布局
- 点击放大/缩小按钮
- 预期：页面内容缩放，工具栏不变形，无溢出

## P1 — 应该通过

### B1：URL 自动补全协议
- 输入 `example.com`（无协议）按回车
- 预期：自动补全为 `https://example.com`

### B2：加载失败不崩溃
- 输入无效 URL（如 `https://999.999.999.999`）
- 预期：webview 显示错误页或空白，不抛出未捕获异常，工具栏保持可用

### B3：多个浏览器 Tab 切换
- 打开两个浏览器 Tab，切换时各自保持独立 URL
- 预期：切换后内容不互相干扰
