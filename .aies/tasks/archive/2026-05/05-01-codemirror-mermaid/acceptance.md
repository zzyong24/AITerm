# 验收标准：CodeEditor 支持 Mermaid 渲染

## P0 验收场景（必须全部通过）

| # | 场景描述 | 输入条件 | 期望结果 |
|---|---------|---------|---------|
| AC-01 | 打开 .md 文件时眼睛图标立即可见 | 打开一个 .md 文件 | 工具栏眼睛图标立即显示，无需手动刷新 |
| AC-02 | 点击眼睛图标进入预览模式 | 在 AC-01 基础上点击眼睛图标 | 切换到预览模式，markdown 正常渲染 |
| AC-03 | 预览模式下 Mermaid 图表正确渲染 | markdown 文件包含 mermaid 代码块 | mermaid 代码块被渲染为 SVG 图表 |
| AC-04 | 预览模式文字清晰可读 | 切换到预览模式 | 文字与背景对比度正常，无看不清的情况 |
| AC-05 | 再次点击眼睛图标退出预览 | 在预览模式下 | 返回编辑模式，编辑器正常编辑 |
| AC-06 | 非 markdown 文件不显示眼睛图标 | 打开 .ts/.js/.json 文件 | 工具栏没有眼睛图标按钮 |
